# Palette Bench

Pick a three-color combination and see it live on a mock website and a mobile app.

**Live:** https://lovrogril.github.io/palette-bench/

## The rule

Two quiet colors, one loud one. Base covers about 60% of the screen, Secondary about 30%, and the Accent about 10% (buttons, highlights, the thing you want clicked).

## What's inside

- **12 palettes from [@niki.aroca](https://www.instagram.com/niki.aroca/reels/)**, sampled from the swatch cards in his color-combination reels. Each card links to its reel.
- **18 web picks**: 10 from [Hook Agency's 2026 website color schemes](https://hookagency.com/blog/website-color-schemes-2026/), reordered into base / secondary / accent, plus 8 common product-UI pairings.

## How to use

- Click a palette, or use ← → to flip through them.
- Select a slot (Base, Secondary, Accent), then click any single color dot to drop it in. You can also use the color picker or type a hex code.
- **Swap base** / **Rotate roles** change which color plays which role. **Random mix** builds a new combo.
- Contrast badges show WCAG readability for text, buttons and the accent.
- **♡ Save** keeps favorites in your browser. **Copy CSS** copies the colors as CSS variables.

It's a single `index.html` with no build step. Open it in a browser or serve the folder.
